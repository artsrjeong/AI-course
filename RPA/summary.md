# RPA Directory Summary

1. **RPA/selenium_test.py**
   - Uses Selenium to automate web interactions.
   - Opens the Naver website, logs in with provided credentials, and then quits the browser.

2. **RPA/selenium_web_crawl.py**
   - Utilizes Selenium to navigate to a specific university's website.
   - Waits for elements to load before interacting with them, clicks a button, and extracts news headlines to print them.

3. **RPA/playwright_web_crawl.py**
   - Employs Playwright to automate web interactions similarly to Selenium.
   - Navigates to the same university's website, waits for elements, and extracts news headlines.

4. **RPA/playwright_test.py**
   - Uses Playwright to visit Hacker News, print the page title, take a screenshot, and then close the browser.

5. **RPA/pyautogui_test.py**
   - Automates keyboard and mouse interactions using the PyAutoGUI library.
   - Demonstrates copying and pasting a Korean phrase using clipboard automation.
