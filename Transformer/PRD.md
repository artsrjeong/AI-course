# Transformer를 이용한 한국어 챗봇 웹 UI 개발

## 1. 프로젝트 목표
기존에 콘솔로 사용자 입력을 받는 챗봇 코드를 Web UI환경으로 바꾼다

## 2. 핵심기능 
기존 콘솔 챗봇 코드 후반부의 콘솔 입력 및 대응 부분을 StreamLit을 이용하여 Web UI로 변경한다.
기존 콘솔 챗봇 코드는 Transformer_Korean_Chatbot.py 파일이다.
생성할 Web UI 챗봇 코드는 Transformer_streamlit.py 파일이다.
